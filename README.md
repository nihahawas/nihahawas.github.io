# Niha Hawas Portfolio

Clean one-page portfolio website for applications.

## Run
Open `index.html` with VS Code Live Server.

## Sections
Home · About Me · My Skills · Projects · Contact

## Project presentation
The Projects section contains 15 projects in a responsive three-column desktop grid. Each card contains a project image, short description, GitHub link, and a clearly marked Live item where a public live URL has not been supplied.

### Project visuals
Project cards use internet-sourced thematic visuals from image hosts for presentation. Replace them with your own screenshots before publishing when you want each image to document the actual interface/output of the corresponding project.
